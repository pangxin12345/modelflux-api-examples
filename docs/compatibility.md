# 兼容范围

示例请求采用常见的 Chat Completions 风格接口。当前文档给出的连接信息为：

- Base URL：`https://modelflux.cn/v1`
- 方法与路径：`POST /chat/completions`
- 默认模型：`deepseek-flash`

本仓库的 Bash/cURL、Python 和 Node.js 示例均发送非流式文本对话请求，设置 `max_tokens` 为 `128`，并使用相同的演示提示词。2026-10-21 三种示例均通过一次真实调用；环境、用量和结果见[验证记录](validation.md)。这不代表所有系统版本和所有账户都已验证。

本次请求标识为 `deepseek-flash`，响应的 `model` 字段为 `deepseek-v4.1-flash`。此处仅记录接口实际返回值，不以该字符串证明底层模型身份或渠道来源。

“兼容接口”表示请求入口采用相似的接口形式，不表示所有能力、参数、错误语义或响应行为全面一致。流式响应、工具调用、多模态输入输出、容灾能力及模型身份真实性均未验证。不要根据这些示例推断上述能力可用，也不要将协议外观当作模型来源证明。
