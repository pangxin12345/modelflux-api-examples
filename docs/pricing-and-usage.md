# 价格与用量

API 调用可能收费。价格和计费规则可能变化，请在使用前查看[价格页面](https://modelflux.cn/pricing)以及账户中显示的实际信息。本文不承诺优惠、固定价格或“官方最低价”；模型名称中的 `-free`（如果出现）也不保证请求免费。

三个示例各发送一次非流式文本对话请求，最大生成长度为 128 tokens。实际用量与费用由服务端计量和账户规则决定；请在账户用量页面核对。避免在循环或自动化任务中未经控制地运行示例。

保护 API Key：只通过本机环境变量传入，不要提交密钥、将其写入公开日志或共享终端记录。仓库里的 `.env.example` 仅为占位模板，示例不会自动加载 `.env`。
